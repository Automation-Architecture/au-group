# n8n-MCP Integration

This project now has n8n-MCP (Model Context Protocol) configured, providing AI-powered assistance for building n8n workflows.

## What is n8n-MCP?

n8n-MCP is a Model Context Protocol server that gives AI assistants comprehensive access to:
- 1,650+ n8n nodes (820 core + 830 community)
- 2,352 workflow templates
- Node documentation and validation tools
- Direct n8n instance management (when configured)

## Files

- `n8n-mcp-setup.md` - Complete setup guide and configuration options
- `n8n-mcp-quick-ref.md` - Quick reference for common commands and workflows

## Getting Started

1. **Restart Cursor** to load the new MCP server
2. Try: "Show me all n8n-mcp tools"
3. Or: "Find templates for webhook automation"

The MCP is now available in all your Cursor chats!

## Configuration Location

MCP configuration: `~/.cursor/mcp.json`

To connect to your n8n instance, see the setup guide for adding API credentials.
